# INTEGRIS Design Hub

Create a modern, premium and responsive website for INTEGRIS, the Design Wing of the Student Innovation Club (SIC), specializing in Strength of Materials, structural design, engineering analysis and innovative mechanical design.

Website Navigation

Create the following sections/pages with smooth navigation:

Home

Strong hero section introducing INTEGRIS.

Tagline: “Engineering Strength. Designing the Future.”

Brief introduction to the Design Wing.

Prominent CTA buttons such as Explore Projects and Meet Our Team.

Use the INTEGRIS logo prominently.

About

Explain what INTEGRIS is.

Mention that it is the Design Wing of the Student Innovation Club.

Focus on Strength of Materials, structural analysis, mechanical design, innovation and practical engineering.

Include Vision, Mission and Core Values.

Our Team

Display team members in modern profile cards.

Include photo, name, role and short description.

Create a layout that can easily be updated with additional members.

Industry Visit

Showcase industry visits conducted by INTEGRIS.

Include company name, location, date, images and key learning outcomes.

Use a timeline or interactive card layout.

Technology

Showcase the technologies and engineering tools used by INTEGRIS.

Include areas such as:

CAD & 3D Design

Finite Element Analysis (FEA)

Structural Analysis

Strength of Materials

Simulation

3D Printing & Prototyping

Present them using visually appealing cards and technical illustrations.

Projects

Create a project showcase section with project cards.

Each card should contain project name, image, short description, technologies used and project status.

Add filtering/categories if appropriate.

Make it easy to add new projects later.

Contact

Provide contact information for INTEGRIS.

Include a contact form with Name, Email, Subject and Message.

Include links/placeholders for social media and other official channels.

Visual Design

Use a dark engineering-inspired theme based primarily on:

Dark Navy Blue — primary color

Black / Charcoal — backgrounds and depth

Orange — highlights, CTAs and important accents

White/light gray — text where needed for readability

The overall visual identity should feel technical, powerful, precise and innovative, rather than looking like a generic college website.

Design Direction

Modern engineering/industrial aesthetic.

Clean geometric layouts.

Strong typography.

Subtle grid and blueprint-inspired background elements.

Use structural/engineering motifs such as beams, load arrows, stress curves, technical drawings and CAD-style linework.

Use subtle animations and hover effects without making the website distracting.

Add smooth scrolling and section transitions.

Use glassmorphism only where it improves the design.

Make the website fully responsive for desktop, tablet and mobile.

Maintain excellent readability and accessibility.

Avoid excessive gradients, unnecessary decorations and generic stock-style visuals.
